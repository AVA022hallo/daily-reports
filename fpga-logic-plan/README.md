# FPGA · 逻辑岗作战台

面向 **华为「硬件技术工程师（实习生）· 逻辑」** 岗位的学习作战台：**聚焦核心技能、关键知识、项目**，可自动重排、全程可视化。
纯静态网页，无后端、无依赖、离线可用；计划数据都在 `assets/` 里，改一行数据页面就变。

> **这一版的规则**
> 1. **每个阶段固定三段：概念 → 刷题（没有可跳过）→ 手写**。段内按顺序做，不排日历、不规定几点、不设每日配额。
> 2. **只算工时**：每一段、每一个阶段、整份计划都只统计小时数；做到哪算哪，进度按工时加权。
> 3. **真题在前、动手在后**：手写任务若是 HDLBits 里有对应章节的功能点，会标「⚠ 前置 FF 0/19」这类提示。

## 4. 怎么用

1. **打开路线图**，看「下一步做什么」那 3 张卡：它们就是按「先概念、再刷题、后手写」的顺序取的。
2. **做完点勾**，工时立刻计入「已完成」；做不完点「只做一半」（记 50%，剩余工时自动减半）；确定不做了点「跳过」（该任务工时从剩余里扣掉）。
3. **手写任务先看「前置」**：黄色 `⚠ 前置 FF 0/19` 表示对应真题还没刷完，先去 HDLBits 页点 `+` 补齐。
4. **HDLBits 用页面上的 `+`**：刷完 7 题点 7 次，任务自动完成，不用两边记。
5. **验收标准是硬门槛**：每张卡都有「验收」，写不出、测不出就是没学会。
6. **每天干了多少去「数据复盘」看**：按「当天完成的任务工时」统计，不做手写补记——完成一个任务记一笔，不完成就不计。
7. **每完成一个阶段看一次「数据复盘」**：三段完成率能告诉你是不是「只刷题不写代码」或者「跳读概念直接动手」。

### 每天的数据从哪来

每天工时 = **当天完成的任务的 `h` 之和**。任务在「路线图」勾完成、或在 HDLBits 把章节刷满（自动完成）时，都会写入当天日期与工时。

| 指标 | 含义 |
| --- | --- |
| 今天 | 当天完成的任务工时 + 任务清单（含 HDLBits 自动完成的） |
| 本周 | 本周一至今的工时 / 有产出天数 / 完成任务数 |
| 近 7 天日均 | 近 7 天总工时 ÷ 7（含没产出的天） |
| 连续投入 | 从今天（或昨天）往前连续有产出的天数 |
| 近 30 天柱图 | 每天一根柱，今天红色；青色=有产出，灰色=空档 |
| 18 周热力图 | 按工时深浅着色（<1 h / 1~2 h / 2~3 h / ≥3 h） |

> 注意：多天做同一个大任务时，工时只在"完成那天"一次性计入——这是"按完成任务计"的代价。所以大任务尽量拆小，或者接受某几天为 0。

## 7. 想改计划？改数据就行

`assets/data-units.js` 里每个任务就是一条记录：

```js
{ id:'P2-03', ph:'P2', seg:'B', t:'手写四件套：触发器族 + 边沿检测 + 复位模板 + 脉冲展宽', h:2, pri:1,
  plat:'Quartus + ModelSim', res:['fpgaDemo'], pre:['hb-ff'],
  d:'FF 真题刷完再动手：三种复位写法各综合一次看 RTL Viewer；边沿检测与脉冲展宽自己写',
  out:'rtl/lib/dff.v、edge_det.v、reset_sync.v、pulse_stretch.v + 各自 tb',
  chk:'4 个 tb 自检通过；综合 0 latch；能说出三种复位写法的资源与风险差异',
  sk:{rtl:1, dd:.5, tool:.3} }
```

| 字段 | 含义 |
| --- | --- |
| **`seg`** | **`C` 概念 / `D` 刷题 / `B` 手写**。渲染时按 C→D→B 排，段内按数组顺序；`h` 决定这段的工时 |
| `h` | 预计小时（所有统计都按它算） |
| `pri` | 1 必做、2 重要、3 加分（页面上标「加分」） |
| `plat` `res` | 平台；资料键（`data-meta.js` 的 `resources`，本机路径或 URL） |
| `pre` | 前置真题（HDLBits 章节 id 数组），页面上显示 `⚠ 前置 FF 0/19` |
| `out` `chk` | 产出物 / 验收标准 |
| `sk` | 能力矩阵权重 |
| `hb` | 关联 HDLBits 章节（对象或数组），刷满自动完成 |
| `opt` | 选做（默认也计入工时，可随时「跳过」） |

`data-meta.js` 里还能改：阶段的三段名称（`cName` / `bName`，默认「概念 / 手写」）、学习路径文案（`path`）、核心技能/关键知识/出口标准、核心 15 项、能力与知识点、项目、JD、资源库。

## 8. 已知边界

- **数据只在本机浏览器**：换电脑/清缓存前用「设置 → 导出进度 JSON」备份。
- **不上传、不联网**：除在线资源的外链，页面不发起任何网络请求。
- **没有「落后」这个概念**：不排日期，也就不存在落后多少天；进度只按工时算。想给自己加期限，自己定一个截止日去对工时即可。\n- **每日数据是记录不是排期**：只在「数据复盘」里按完成记录折算，用来衡量今天/这周干了多少；它不会反过来影响任务顺序。
- **HDLBits 初始进度**按截图记为 34/179；旧版数据（v1/v2/v3）会自动迁移。
- 计划是**草稿不是考卷**：顺序对了比排得细更重要，改它比执行它更重要。
