# P2-05 手写：参数化计数器 + 分频器

> **类型**：手写 RTL + 自检 Testbench  
> **目标文件**：`rtl/lib/counter_param.v`、`rtl/lib/clk_div.v`  
> **配套 TB**：`tb/tb_counter_param.v`、`tb/tb_clk_div.v`  
> **建议用时**：3～4 小时  
> **对应知识点**：参数化、模计数器、终端计数、加载/使能/方向优先级、分频周期、占空比、相位、自检 TB

---

## 1. 任务概览

| 题目 | RTL 文件 | 核心目标 | 难度 |
| :--- | :--- | :--- | :--- |
| P2-05-A | `rtl/lib/counter_param.v` | 参数化加/减计数器，支持加载、使能、终端计数 | 中 |
| P2-05-B | `rtl/lib/clk_div.v` | 参数化整数分频，周期/占空比/相位正确 | 中 |
| TB-A | `tb/tb_counter_param.v` | 验证多组 `W/MAX`、回卷、加载优先级、`tc` | 中 |
| TB-B | `tb/tb_clk_div.v` | 测量多组 `DIV` 的周期、高低时间、复位相位 | 中 |

这道题不是“写一个计数器”这么简单，重点是把下面几件事讲清楚：

1. **参数化**：`W`、`MAX`、`DIV` 改了以后，逻辑仍然正确；
2. **优先级**：复位 > 加载 > 使能 > 计数；
3. **终端条件**：`MAX=9` 时在第 9 个状态回卷，不是在第 15 个状态回卷；
4. **终端计数**：`tc` 是电平，不是单周期脉冲；
5. **分频器**：周期、占空比、复位后的初始相位都要说清楚；
6. **Testbench**：要能量出频率和占空比，而不是只看波形“差不多”。

## 2. 通用规则

### 2.1 目录结构

```text
rtl/
  lib/
    counter_param.v
    clk_div.v
tb/
  tb_counter_param.v
  tb_clk_div.v
```

如果目录不存在，先创建 `rtl/lib/` 和 `tb/`。

### 2.2 RTL 编码约束

- 使用 Verilog-2001/2005 可综合子集，文件扩展名 `.v`；
- 时序逻辑统一写成：

```verilog
always @(posedge clk or negedge rst_n)
```

- 时序逻辑用非阻塞 `<=`，组合逻辑用阻塞 `=`；
- 禁止在 RTL 中使用：
  - `initial`
  - `#delay`
  - `$display`
  - `force/release`
  - `while` 等不可综合构造
- 禁止锁存器：组合 `always` 的所有分支都要赋值；
- 禁止门控时钟；需要“慢一拍”就用使能；
- 所有输出在复位后必须是确定的 0/1，不能有 X/Z；
- 不调用厂商原语或现成 IP。

### 2.3 TB 编码约束

每个 TB 必须：

1. 产生 `clk`（建议 10 ns 周期）和 `rst_n`；
2. 使用自检式比较，不能只打印波形；
3. 有错误计数器，最后输出：

```text
TEST PASSED
```

或：

```text
TEST FAILED: N errors
```

4. 有超时 watchdog，例如 2000 个时钟周期后 `$fatal`；
5. 在 `posedge` 后 `#1` 再采样，避免 NBA 竞争；
6. 异步复位检查在 `#1` 后立即做；
7. 至少包含：定向测试 + 随机测试 + 复位中途测试；
8. 必须覆盖多组参数，否则“参数化”没有被真正验证。

> **复位小坑**：如果 TB 在 t=0 直接把 `rst_n` 设为 0，可能没有产生 `negedge`。建议先给 `rst_n=1`，`#1` 后再拉低，制造一个真正的下降沿。

## 3. P2-05-A：`counter_param.v` —— 参数化计数器

### 3.1 题目

实现一个参数化的**可加/可减、可加载、带终端计数**的计数器：

- `W` 决定位宽；
- `MAX` 决定计数终端值，计数范围是 `0 ~ MAX`；
- 支持异步复位、同步加载、计数使能、加/减方向；
- 输出当前值 `q` 和终端计数 `tc`。

### 3.2 接口（必须一致）

```verilog
module counter_param #(
    parameter integer W   = 4,
    parameter integer MAX = (1 << W) - 1
)(
    input  wire         clk,
    input  wire         rst_n,    // 异步复位，低有效
    input  wire         en,       // 计数使能
    input  wire         load,     // 同步加载
    input  wire         up_down,  // 1=加，0=减
    input  wire [W-1:0] din,      // 加载值
    output reg  [W-1:0] q,        // 当前计数值
    output wire         tc        // 终端计数，电平
);
```

### 3.3 参数约束

- `W >= 1`；
- `1 <= MAX < 2^W`；
- `MAX` 默认是 `2^W - 1`，例如 `W=4` 时默认 15；
- 如果 `MAX=9`，计数器就是 0～9 的十进制计数器，周期是 `MAX+1=10` 个计数；
- `din` 只保证在 `0 ~ MAX` 范围内；超出范围的行为不定义，TB 不测试非法加载值。

### 3.4 功能要求

`q` 是寄存器输出，`tc` 是组合输出，跟随 `q` 和 `up_down` 变化。

**优先级：异步复位 > 同步加载 > 计数使能 > 保持。**

| rst_n | load | en | 行为 |
| :-: | :-: | :-: | :--- |
| 0 | x | x | `q <= 0`，异步，立即生效 |
| 1 | 1 | x | `q <= din`，load 优先于 en |
| 1 | 0 | 0 | `q` 保持 |
| 1 | 0 | 1 | 根据 `up_down` 加 1 或减 1 |

**加计数：**

```text
q == MAX  →  q <= 0
否则       →  q <= q + 1
```

**减计数：**

```text
q == 0    →  q <= MAX
否则       →  q <= q - 1
```

所以它是一个 **模 `MAX+1` 的加/减计数器**。

### 3.5 终端计数 `tc`

```text
up_down = 1 时：tc = (q == MAX)
up_down = 0 时：tc = (q == 0)
```

注意：

> `tc` 是**电平**，不是单周期脉冲。  
> 只要 `q` 在终端，`tc` 就为 1，和 `en` 无关。  
> 因此复位后如果 `up_down=0`，`q=0`，`tc` 会立即为 1；这不是 bug，是“向下计数已经到达终端”。

如果你需要“回卷脉冲”，可以额外做：

```text
wrap = tc && en && !load
```

但本题只要求 `tc` 电平；`wrap` 是加分项。

### 3.6 时序例子

以 `W=4, MAX=9, en=1, load=0` 为例：

**加计数：**

```text
q:  8 → 9 → 0 → 1 → 2 → ...
tc: 0 → 1 → 0 → 0 → 0 → ...
```

**减计数：**

```text
q:  1 → 0 → 9 → 8 → 7 → ...
tc: 0 → 1 → 0 → 0 → 0 → ...
```

**加载：**

```text
q=5, load=1, din=2            → 下一个时钟沿 q=2
q=2, load=0, en=1, up_down=1  → 下一个时钟沿 q=3
```

**使能关闭：**

```text
en=0 时，无论 din/up_down 怎么变，q 都保持
```

### 3.7 TB 必测项

`tb_counter_param.v` 至少实例化三组参数：

```verilog
counter_param #(.W(4), .MAX(9))   u_dec;    // 非 2 的幂
counter_param #(.W(8), .MAX(255)) u_full;   // 满位宽
counter_param #(.W(3), .MAX(4))   u_small;  // 小位宽、非满
```

覆盖：

1. **异步复位**
   - 时钟运行中拉低 `rst_n`，`#1` 后 `q=0`；
   - 复位期间 `load=1, din=7`，`q` 仍为 0；
   - 复位释放后，第一个时钟沿才允许加载/计数。

2. **加载优先级**
   - `load=1, en=0` 时也能加载；
   - `load=1, en=1` 时加载优先，不计数；
   - 加载 `0`、`MAX`、中间值都测一遍。

3. **加计数回卷**
   - 从 `MAX-1` 开始，连续计数到 `MAX`，再回到 0；
   - 回卷后 `tc` 必须变 0；
   - `MAX=9` 时不能在 15 才回卷，这是最常见错误。

4. **减计数回卷**
   - 从 1 开始，减到 0，再回到 `MAX`；
   - 回卷后 `tc` 必须变 0；
   - `q=0` 时不能出现 4 位全 1 的中间错误状态。

5. **使能和方向**
   - `en=0` 连续 3 拍，`q` 不变；
   - `en=0` 时改变 `up_down`，下一拍按新方向计数；
   - `up_down` 在计数过程中切换，检查下一拍方向正确。

6. **终端计数 `tc`**
   - 加计数到 `MAX` 时 `tc=1`；
   - 减计数到 0 时 `tc=1`；
   - 回卷后 `tc=0`；
   - `en=0` 但停在终端时，`tc` 仍为 1；
   - 复位后分别测 `up_down=1`（`tc=0`）和 `up_down=0`（`tc=1`）。

7. **随机回归**
   - 用参考模型维护期望的 `q` 和 `tc`；
   - 至少 200 个随机周期，随机 `load/en/up_down/din`；
   - 每个 `posedge` 后 `#1` 比较，发现 X/Z 直接报错。

### 3.8 常见坑

- **用 `q+1` 直接回卷**：`MAX=9` 时 `9+1=10`，不是 0；必须显式判断 `q==MAX`。
- **用 `q-1` 直接下溢**：0 减 1 会变成全 1；必须显式判断 `q==0`。
- **load 和 en 优先级搞反**：题目要求 load 优先。
- **`tc` 写成单周期脉冲**：题目要求电平。
- **`tc` 只看 `q==MAX`**：向下计数时终端是 0，不是 MAX。
- **复位后 `tc` 期望为 0**：`up_down=0` 时 `tc` 应为 1，TB 要按方向判断。

## 4. P2-05-B：`clk_div.v` —— 参数化分频器

### 4.1 题目

实现一个参数化时钟分频器：

- 输入时钟 `clk_in`；
- 输出时钟 `clk_out`；
- 分频比 `DIV` 可参数化；
- 输出周期 = `DIV` 个输入时钟周期；
- 偶数分频时占空比 50%；
- 奇数分频时，高电平比低电平多一个输入周期（题目约定）。

### 4.2 接口（必须一致）

```verilog
module clk_div #(
    parameter integer DIV = 4   // 分频比，>=2
)(
    input  wire clk_in,
    input  wire rst_n,    // 异步复位，低有效
    output reg  clk_out
);
```

### 4.3 参数、相位和占空比

定义：

```text
LOW  = DIV / 2          // 低电平输入周期数，向下取整
HIGH = DIV - LOW        // 高电平输入周期数，向上取整
```

**约定：**

- 复位时内部相位计数 `cnt=0`，`clk_out=0`；
- 每个 `posedge clk_in` 更新 `cnt`，在 `0 ~ DIV-1` 循环；
- `cnt < LOW` 时 `clk_out=0`，`cnt >= LOW` 时 `clk_out=1`；
- 因此低电平占 `LOW` 个计数状态（`0 ~ LOW-1`），高电平占 `HIGH` 个计数状态（`LOW ~ DIV-1`）；
- 从复位释放后的第一个 `posedge` 起数，第 `LOW` 个 `posedge` 时 `clk_out` 拉高，第 `DIV` 个 `posedge` 时拉低；
- `clk_out` 只在 `posedge clk_in` 后变化，不能有组合毛刺。

**DIV 与输出关系：**

| DIV | LOW | HIGH | 输出周期 | 占空比（高/周期） |
| :-: | :-: | :-: | :-: | :-: |
| 2 | 1 | 1 | 2 个输入周期 | 50% |
| 3 | 1 | 2 | 3 个输入周期 | 66.7% |
| 4 | 2 | 2 | 4 个输入周期 | 50% |
| 5 | 2 | 3 | 5 个输入周期 | 60% |
| 8 | 4 | 4 | 8 个输入周期 | 50% |

> 奇数分频不可能用“整数个输入周期”把高低电平完全平分，所以必然有一边多一个周期。本题固定“高电平多一个”，即 `HIGH = ceil(DIV/2)`。

### 4.4 功能要求

- `DIV >= 2`；`DIV=1` 不作为本题要求（直通是另一个功能）；
- 异步复位：`rst_n=0` 时 `clk_out=0`，内部计数器清零；
- 复位释放后，输出从低电平开始；
- 输出频率：

```text
f_out = f_in / DIV
T_out = DIV × T_in
```

- 偶数 `DIV`：高、低各 `DIV/2` 个输入周期，50%；
- 奇数 `DIV`：高 `ceil(DIV/2)`，低 `floor(DIV/2)`；
- 输出必须由寄存器产生，不能用计数器组合逻辑直接 `assign clk_out = ...`；
- `clk_out` 不能出现毛刺、尖峰或 X/Z。

### 4.5 TB 必测项

`tb_clk_div.v` 至少实例化：

```verilog
clk_div #(.DIV(2)) u_div2;
clk_div #(.DIV(3)) u_div3;
clk_div #(.DIV(4)) u_div4;
clk_div #(.DIV(5)) u_div5;
clk_div #(.DIV(8)) u_div8;
```

覆盖：

1. **周期**
   - 相邻两个 `posedge clk_out` 的时间差 = `DIV × T_in`；
   - 用 `$time` 记录边沿，容差 0.1～0.2 ns；
   - 不要只数一个周期，建议连续测 4 个周期，逐个检查。

2. **高/低时间**
   - 高电平时间 = `HIGH × T_in`；
   - 低电平时间 = `LOW × T_in`；
   - `DIV=2/4/8` 时两者相等；
   - `DIV=3/5` 时高电平比低电平多一个输入周期。

3. **占空比**
   - 偶数分频：50%；
   - 奇数分频：`HIGH/DIV`，例如 `DIV=5` 时 60%，不是 50%。

4. **复位**
   - 在 `clk_out=1` 时拉低 `rst_n`，`#1` 后 `clk_out` 必须为 0；
   - 复位释放后，`clk_out` 先保持低 `LOW` 个输入周期，再拉高；
   - 复位中途不能出现半个高脉冲或毛刺。

5. **相位**
   - 复位释放后的第一个输入 `posedge` 算第 1 拍；
   - 数 `posedge clk_in`：第 `LOW` 个 `posedge` 时 `clk_out` 拉高，第 `DIV` 个 `posedge` 时拉低；
   - 用计数验证，不要只看频率。

6. **边界**
   - `DIV=2` 最小偶数；
   - `DIV=3` 最小奇数；
   - `DIV=5` 非 2 的幂奇数；
   - `DIV=8` 2 的幂偶数。

7. **随机复位**
   - 随机在 `clk_out` 高/低期间拉低复位；
   - 每次释放后重新检查周期、高低时间和相位；
   - 检查 `clk_out` 不出现 X/Z。

### 4.6 常见坑与工程注意

- **用 `tc` 直接翻转输出**：如果计数器 `MAX=DIV-1`，每到一个 `tc` 翻转一次，得到的是 `2×DIV` 分频，不是 `DIV` 分频。
- **奇数分频写成 50%**：单个上升沿计数器做不到，必须有半周期相位或双边沿处理；本题不要求 50%。
- **组合输出**：`assign clk_out = (cnt < HALF);` 可能产生毛刺，必须寄存。
- **复位释放相位不对**：`clk_out` 可能从高电平开始，TB 要按题目约定检查。
- **`DIV=1`**：本题不要求；如果实现直通，要单独说明，不能和 `DIV>=2` 的行为混在一起。
- **分频时钟直接驱动大量逻辑**：实际工程优先用 clock enable 或 MMCM/PLL；如果必须用逻辑分频时钟，要加时钟缓冲和 `create_generated_clock` 约束。本题是学习分频原理，不鼓励在复杂设计里滥用。

## 5. TB 设计方法

### 5.1 通用结构

每个 TB 建议包含：

```verilog
`timescale 1ns/1ps

module tb_xxx;
    reg clk;
    reg rst_n;
    integer errors;
    integer timeout_cnt;

    // 时钟
    initial begin
        clk = 0;
        forever #5 clk = ~clk;   // 10 ns 周期
    end

    // 复位
    initial begin
        rst_n = 1;
        #1 rst_n = 0;            // 制造 negedge
        #20 rst_n = 1;
    end

    // 超时 watchdog
    initial begin
        timeout_cnt = 0;
        forever begin
            @(posedge clk);
            timeout_cnt = timeout_cnt + 1;
            if (timeout_cnt > 2000) begin
                $fatal(1, "TIMEOUT");
            end
        end
    end

    // 检查任务
    task check_q(input [31:0] got, input [31:0] exp, input [127:0] msg);
        begin
            if (got !== exp) begin
                errors = errors + 1;
                $display("FAIL @%0t: %0s got=%0d exp=%0d",
                         $time, msg, got, exp);
            end
        end
    endtask

    initial begin
        errors = 0;
        // 测试激励
        // ...
        if (errors == 0) $display("TEST PASSED");
        else             $display("TEST FAILED: %0d errors", errors);
        $finish;
    end
endmodule
```

### 5.2 计数器 TB 检查矩阵

| 测试 | 激励 | 检查 |
| :--- | :--- | :--- |
| 异步复位 | 任意时刻 `rst_n=0` | `q==0`，`tc` 按方向正确 |
| 加载 | `load=1, din=0/MAX/中间值` | `q==din` |
| 加载优先 | `load=1, en=1` | 不计数 |
| 使能关闭 | `en=0` 连续多拍 | `q` 不变 |
| 加回卷 | `q=MAX-1` 起 | `MAX → 0` |
| 减回卷 | `q=1` 起 | `0 → MAX` |
| 方向切换 | `en=0` 时改 `up_down` | 下一拍方向正确 |
| `tc` 电平 | 停在终端、`en=0` | `tc` 仍为 1 |
| 随机回归 | 200 拍随机 | 参考模型一致 |

### 5.3 分频器 TB 检查矩阵

| 测试 | 激励 | 检查 |
| :--- | :--- | :--- |
| 周期 | 连续跑多个周期 | `posedge` 间隔 = `DIV×T_in` |
| 高电平 | 测 `posedge` 到 `negedge` | = `HIGH×T_in` |
| 低电平 | 测 `negedge` 到 `posedge` | = `LOW×T_in` |
| 占空比 | 高/周期 | 偶数 50%，奇数 `HIGH/DIV` |
| 初始相位 | 复位释放后 | 先低 `LOW` 拍 |
| 复位 | 高/低期间拉低 | `#1` 后输出 0 |
| 边界 | `DIV=2/3/5/8` | 周期、占空比正确 |
| X/Z | 全程 | 输出不能为 X/Z |

### 5.4 测量建议

- 用 `$time` 记录 `posedge clk_out` 和 `negedge clk_out`；
- 时钟周期 10 ns 时，期望值是 10 ns 的整数倍；
- 容差建议 0.1～0.2 ns，避免 delta 延迟误判；
- 不要用 `#1` 后的时间当边沿时间；
- 分频器相位最好通过“数 `posedge clk_in`”验证，而不是只看频率；
- 计数器每个 `posedge` 后 `#1` 采样，避免 NBA 竞争。

### 严格验收

- 只测默认参数 → 参数化部分不得分；
- TB 只打印波形、不自动比较 → TB 不得分；
- 改错 RTL 后 TB 仍 PASS → 视为覆盖不足；
- 计数器在 `MAX=9` 时从 9 跳到 15，或从 0 减到 15 → 功能错误；
- 分频器 `DIV=5` 输出 50% 占空比 → 不符合本题约定。

## 8. 加分项

### 8.1 计数器

- 增加 `STEP` 参数，支持步长不为 1；
- 增加 `SATURATE` 参数：到终端后保持，不回卷；
- 增加 `wrap` 单周期脉冲输出；
- 增加同步置位/预置数功能。

### 8.2 分频器

- 额外输出 `tick`：每 `DIV` 个输入周期产生一个单周期使能；
- 实现 `DIV=1` 直通模式（单独说明）；
- 用 `counter_param` 实现 `clk_div`，并写集成 TB；
- 用 `tick` 驱动下游计数器，避免直接使用分频时钟。

### 8.3 集成题（需先实现 `tick` 加分项）

```text
clk_in → clk_div → tick → counter_param
```

要求：

- 每 `DIV` 个输入周期，计数器加 1；
- 计数器到 `MAX` 后回卷；
- 验证计数器更新频率 = `f_in / DIV`；
- 验证复位后第一个 `tick` 不会让计数器误加。

## 9. 快速自测

### Q1. `W=4, MAX=9`，加计数一个完整周期是多少个计数？

**答**：10 个，状态为 0～9。

### Q2. `DIV=5`，输出周期、高低时间、占空比是多少？

**答**：周期 5 个输入周期；低 2 拍、高 3 拍；占空比 60%。

### Q3. 为什么 `up_down=0` 时复位后 `tc` 可能为 1？

**答**：向下计数的终端是 0，`q=0` 已经到达终端；`tc` 是电平，不是脉冲。

### Q4. 为什么奇数分频很难做到 50%？

**答**：周期是奇数个输入周期，无法用整数个周期把高、低完全平分；单上升沿计数器必然有一边多一拍。

### Q5. `tc` 和“回卷脉冲”有什么区别？

**答**：`tc` 是终端电平，停在终端就为 1；回卷脉冲只在真正发生回卷的那一拍为 1。

### Q6. 为什么分频器输出必须寄存？

**答**：用计数器组合逻辑直接输出可能产生毛刺；寄存后输出只在时钟沿变化，波形干净。

## 10. 最终检查清单

- [ ] `counter_param` 的 `W/MAX` 可以改，逻辑仍然正确；
- [ ] `MAX=9` 时在第 9 个状态回卷，不是在 15 回卷；
- [ ] 加计数和减计数都能正确回卷；
- [ ] `load` 优先于 `en`；
- [ ] `en=0` 时 `q` 保持；
- [ ] `tc` 是电平，方向正确，回卷后清零；
- [ ] `clk_div` 的 `DIV` 可以改，周期 = `DIV×T_in`；
- [ ] 偶数分频 50%，奇数分频高电平多一拍；
- [ ] 复位后 `clk_out` 从低电平开始；
- [ ] `clk_out` 由寄存器输出，无毛刺；
- [ ] TB 覆盖多组参数、复位、回卷、相位、X/Z；
- [ ] TB 能自动输出 `TEST PASSED` / `TEST FAILED`；
- [ ] 改错 RTL 后 TB 能报错（建议做一次变异测试）。

## 11. 一句话总结

> **计数器是把“状态 + 方向 + 终端条件”写对；分频器是把“周期 + 占空比 + 相位”写对；Testbench 是把这三件事量出来，而不是只看波形。**
